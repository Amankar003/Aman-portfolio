Aman Kar portfolio: source code
1. Install Node.js, then run:  npm install   (installs react, framer-motion, three@0.128.0, esbuild)
2. Edit your details in  src/data.js   (name, skills, projects, links, photos)
3. Build:  node build.mjs   -> creates dist/index.html (single file, deploy anywhere: Netlify, Vercel, GitHub Pages)
